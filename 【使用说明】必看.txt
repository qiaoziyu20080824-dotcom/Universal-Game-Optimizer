  3. 🎯 进阶自选项（按需自由选择，高风险项默认关闭并设显式确认）：
     - 【开启独显直连与全局渲染绑定】：默认开启！台式机与直连本锁定全局独显；双显卡混合游戏本定向为游戏绑定独显渲染，杜绝 DWM 异常唤醒与 30W 待机发热。
     - 【开启 CPU 负压与 GPU 动态调谐】：
       * 自动化脚本极其安全保守：遵循科学负压规范，面向未知硬件，全核 AMD Curve Optimizer 负压幅度严格限制在极其安全的 -5 ~ -10 Counts (默认 -8 Counts，等效降压约 30mV，上限绝不上冲 -20~-25)，既大幅压制高负载积热，又彻底杜绝待机空闲低电压死机！
       * 勾选开启后，脚本将在优化中自动执行 30 秒 CPU 深度热阻与温升斜率探测采样，采用严谨多变量连续温控模型推导最佳甜点能效区间。
       * 可选搭配【CoreCycler 瞬态轮询复核】或 25 秒双满载复核，唯有 100% 稳定才允许持久化开机生效。
       * 解锁 GPU Boost 满血功耗墙（Power Limit，移动端安全交由 Dynamic Boost 托管），拒绝机械锁频，待机 210MHz 正常回落，满载动态冲刺最高 Boost。
       * 若不勾选，则保持 100% 纯系统级安全优化，绝不触碰芯片电压频率。
     - 【启用 IRQ 中断亲和性解耦分流（极客专属 · 高风险 · 默认关闭）】：
       * 核心原理：Windows 默认将显卡、网卡、NVMe 中断全部堆在 CPU 0 (Core 0) 上处理，交火时 Core 0 易被 DPC 中断占满造成掉帧瓶颈。利用注册表 Affinity Policy 机制，将物理网卡中断绑定在物理 Core 2，将显卡中断绑定在物理 Core 4，彻底将 Core 0 从硬件中断中解放出来，大幅降低 DPC 延迟峰值！
       * 智能动态拓扑防呆：脚本强制调用 NativeCpuTopology 硬件探测，必须在目标机具备 Core 2 与 Core 4（至少 6~8 线程）时才允许分配，绝不设置非法亲和性掩码。
       * 多队列 RSS 网卡严苛避让：智能检测网卡 RSS (Receive Side Scaling) 状态。若网卡已启用多队列 RSS，说明已由 MSI-X 多向量动态分流，脚本将坚决自动跳过单核绑定，严禁盲目覆盖引发性能倒退！
       * 100% 精准无损可逆：优化前完整记录原始 DevicePolicy 与 AssignmentSetOverride，还原时 100% 原样恢复。
     - 【采用 CoreCycler 瞬态轮询复核（高风险 · 深度验证 · 默认关闭）】：
       * 借鉴开源超频神器 CoreCycler 验证逻辑：利用 Windows API 单独将算力锁定在单核上逐核轮询执行高低交替突发冲刺与瞬间撤载（制造强烈 dI/dt 瞬态冲击与电压骤降），同时实时监测系统事件日志中的 WHEA-Logger Event 18 警告。唯有扛过单核低载瞬态冲击的 Curve Optimizer 参数，才是日常游戏中不蓝屏的黄金参数！
     - 【Windows Defender 杀毒配置】：
       * 保持开启（默认推荐）：日常娱乐防毒外挂拦截；
       * 彻底关闭：极致释放 3%~5% CPU 与磁盘占用，适合纯竞技游戏玩家。

【遇到系统弹窗或安全软件怎么处理？】（常见 2 种情况）：
--------------------------------------------------------------------------------------
  1. 出现蓝色大卡片提示“Windows 已保护你的电脑”？
     原因：从网络、微信、QQ 或网盘下载的压缩包，Windows 会附带 SmartScreen 提示。
     解决：点击卡片上的【更多信息】 -> 选择【仍要运行】即可。

  2. 电脑装了“360安全卫士”或“电脑管家”弹出阻止警告？
     原因：优化需要配置高精度时钟与显卡 MSI 硬件中断，第三方杀毒软件会提示底层变动。
     解决：运行前建议先右键退出 360 / 电脑管家；或在弹窗时选择【允许本次操作】。
     （注：火绒或 Windows 原生安全中心不会误报拦截）。
